PROJECT REPORT: Autonomous Robot Obstacle Detection and Avoidance

Overview:
This project implements a computer vision system designed for mobile robot navigation and collision avoidance.

Implementation Details:
The core script obstacle_detection.py runs YOLOv8 object detection on a live camera stream. The frame is partitioned into safety corridors (Left, Center, Right). Objects entering the lower region trigger real-time steering commands (STEER LEFT, STEER RIGHT, EMERGENCY STOP, or PATH CLEAR) displayed on a HUD banner overlay.

Results:
The pipeline operates smoothly at over 30 FPS and provides instant steering commands based on object proximity.

Limitations:
Distance estimation is based on 2D image bounding box positions (y-axis depth heuristic) rather than calibrated 3D depth camera sensors.
