PROJECT REPORT: Parking Slot Occupancy Detection

Overview:
This project demonstrates parking space tracking through an interactive 3x3 grid simulation built using OpenCV.

Implementation Details:
The script parking.py creates a custom window rendering asphalt road graphics and yellow lane divides. An interactive mouse callback function registers clicks on any of the 9 grid zones. When occupied, the slot draws a styled car model and changes its border to red. The top dashboard calculates remaining capacity instantly.

Results:
The interface runs smoothly at 60 FPS and updates spot counts instantaneously upon mouse interaction.

Limitations:
Grid dimensions are fixed at 3x3. Expanding to irregular parking lot layouts would require custom polygon coordinate definitions.
